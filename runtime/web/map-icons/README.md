# 地图图标

来源：[MurkyYT/cs2-map-icons](https://github.com/MurkyYT/cs2-map-icons)。该社区项目从 CS2 游戏资源中提取地图图标；素材版权属于 Valve Corporation。

本目录仅保留控制台使用的十张 PNG，随部署复制，本地页面不请求外部图标服务。来源固定到提交 `6dcfb3a770afc08a16c4e843c51b873cac7fc4d5`，下载地址、文件大小及 SHA256 见 `sources.json`；更新图标时需同步清单。

中文地图名称取自本机 CS2 的简体中文语言资源，由 `maps.mjs` 维护。图标素材与本项目自有代码分别归属其各自权利人。
