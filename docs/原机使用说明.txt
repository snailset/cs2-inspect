CS2 本地检视控制台 — 使用说明
更新日期：2026-11-15

一、统一入口
推荐双击 E:\CS2Inspect\检视控制台.html，再点击“打开本地检视控制台”。
首次使用时，浏览器可能询问是否打开本地应用，请确认打开。
HTML 入口会调用本机小型启动器，打开后台与控制台；纯网页无法自行启动 Windows 程序。
备用入口：E:\CS2Inspect\打开检视控制台.cmd（双击即可，不必管理员运行）。
后台已运行时，直接打开 http://127.0.0.1:17830/ 即可。
启动器只注册了当前 Windows 用户的 cs2inspect://open 协议，没有添加开机自启。

二、启动、停止
“启动检视”：自动启动数据库、独立服务端，以 -insecure 模式打开 CS2 并连接本机。
等待地图加载后，选择任意阵营。页面显示“已连接本机检视服”即可开始配装。
如果原来的普通模式 CS2 正在运行，需要先正常退出，再点击启动。
如果检视客户端已经打开但没有连接，复制页面上的连接指令到控制台：
connect 127.0.0.1:27015

“停止检视服务”：关闭本地游戏服务端和数据库，控制台页面仍保持可用。
这会断开本地地图连接；不会强制关闭原版 CS2 客户端。
如要连控制台后台也一起关闭，可运行 Stop-Inspect.cmd。
旧的 Start-Inspect.cmd / 启动本地检视.cmd 仍可以直接启动游戏，但日常推荐统一控制台入口。

三、两级饰品选择与实时应用
先选择“枪械 / 刀具 / 手套”分类，再按两级选择：
  枪械：AK-47、AWP 等 → 对应的具体皮肤
  刀具：蝴蝶刀、爪子刀等 → 对应的具体皮肤
  手套：运动手套、专业手套等 → 对应的具体皮肤
第二级搜索框只搜索当前大类，避免不同武器、手套混在一起。
当前有 35 类枪械、20 类刀具、8 类手套；合计 2161 个饰品条目。

选择皮肤后，填写图案模板和磨损，点击“应用到游戏”。
后台直接写入配装并向本地饰品插件发送刷新，无需手动输入 moeub 饰品代码。
应用枪械会自动发放所选枪械，替换同槽位装备，并尝试切到对应持有视角。
应用刀具只更新刀具并切到持刀视角；应用手套保留当前持有的武器。
无法确认视角切换时会尝试恢复原持有视角，页面会显示实际确认结果。
刚进地图时请先选好阵营，再应用或点击“刷新游戏饰品”。
按 F 检视，按 R 换弹。现在弹匣正常消耗，备用弹药无限，必须换弹才能继续射击。
“保存搭配”会写入“我的搭配”，T / CT 两队同时生效。
图案模板：0–1000；磨损：0–1；支持名称标签、StatTrak、最多 5 张贴纸。
贴纸使用默认位置和角度，暂不提供自由移动和旋转。
饰品列表显示缩略图，选中后在右侧显示大图；切换款式即可预览，无需先应用到游戏。
图片是款式参考图，不随图案模板、磨损、名称标签或贴纸变化；具体效果以游戏内为准。
首次查看时，后台从 WeaponPaints 的公开图片库按需下载，保存在 E:\CS2Inspect\data\preview-images。
已经缓存的图片可离线查看；未缓存的图片需要联网。图片加载失败时，可点击大图区域的“重试图片”。
浏览器只从本机后台读取图片；图片下载不涉及 Steam 登录，也不会改动游戏文件。

四、关于“请求验证失败”
旧版后台每次重启都会更换令牌，旧页面因此失效。
新版保留本机验证令牌，并在页面验证过期时自动重新获取后重试一次。
升级后，请把原先打开的旧网页刷新一次，加载新版页面。
状态查询与饰品刷新已按顺序执行，避免同时连接游戏导致偶发刷新失败。
本机访问限制、请求来源验证仍然保留；无需关闭防火墙或浏览器保护。
UB / moeub 的 sm_skin、sm_glove 指令不直接兼容本插件；直接用本地页面即可。

五、官匹与原版文件
结束检视后，正常退出 CS2，再从 Steam 正常启动官匹。
-insecure 只作为检视入口的临时启动参数，没有写入 Steam 永久启动选项。
插件只在 E:\CS2Inspect\server 副本内，没有加入原版游戏目录。
不能承诺第三方插件绝对零封号风险；官匹前必须退出此次检视客户端并正常重开。

六、文件与磁盘
统一入口：E:\CS2Inspect\检视控制台.html
备用入口：E:\CS2Inspect\打开检视控制台.cmd
说明：E:\CS2Inspect\使用说明.txt（页面右上角也可打开）
独立服务端：E:\CS2Inspect\server
数据库、账号配置与搭配：E:\CS2Inspect\data
网页：E:\CS2Inspect\web
饰品图片缓存：E:\CS2Inspect\data\preview-images
便携程序：E:\CS2Inspect\tools
网页、数据库日志：E:\CS2Inspect\logs
当前游戏控制台日志：E:\CS2Inspect\server\game\csgo\addons\metamod\console.log
上版脚本与网页备份：E:\CS2Inspect\backups\control-panel-v1
下载包：E:\CS2Inspect_Downloads
临时文件、缓存：D:\codex
独立服务端约 71 GiB；没有安装 Windows 服务或添加开机自启。
分页文件已配置到 D:\pagefile.sys，下次重启才生效；不要手动删除正在使用的 C 盘分页文件。

七、本地隔离
数据库监听 127.0.0.1:3307，网页监听 127.0.0.1:17830，RCON 监听 127.0.0.1:27015。
客户端和服务端均以 -insecure 运行；服务端为 sv_lan 1。
Windows 专用、公用防火墙已启用，两条外部入站阻止规则仅针对独立服务端程序。
CS2 UDP 可能监听通配地址，因此隔离依赖防火墙规则保持启用。
启动时直接读取并核对规则属性，校验失败则拒绝启动。
不要设置端口转发或公开此服务，不要分享 data\secrets.json。
已验证本机连接和防火墙规则；未从另一台物理设备执行外部访问阻断测试。

八、本次验证
已验证服务停止后控制台仍可用，网页后台能重新启动数据库与地图。
已验证旧令牌自动恢复、非本机网页来源请求被拒绝。
已验证枪械、刀具、手套三个分类标签与两级饰品选择，以及浏览器实际提交应用请求。
你已确认运动手套“潘多拉之盒”在游戏中正常显示，并且 AK 可以正常换弹。
已验证枪械、刀具、手套图片加载、缩略图与大图切换，以及 E 盘本地图片缓存。
原版游戏关键文件保持不变；数据库与饰品插件运行正常。
更新客户端后若出现版本不一致，独立服务端也需要更新；不要把插件复制回原版目录。

定向应用扩展：LocalInspectBridge。先读完数据库，再单次更新所选槽位；不再调用整套武器刷新。
扩展源码与构建脚本：E:\CS2Inspect\extensions\LocalInspectBridge。原版客户端目录保持独立。
