# CS2 本地检视控制台

## 启动与停止

打开安装目录的 `检视控制台.html`，点“打开本地检视控制台”，再点“启动检视”。备用入口是同目录 `打开检视控制台.cmd`。后台已启动时直接访问 <http://127.0.0.1:17830/>。

如果普通模式的 CS2 正在运行，先退出。启动器会通过 Steam 使用本次临时参数 `-insecure -console +connect 127.0.0.1:27015`，没有修改 Steam 永久启动选项。

等待地图加载后选阵营。若没有自动进入，在游戏控制台输入：

```text
connect 127.0.0.1:27015
```

服务端默认关闭联网/离线热身。配置请求将热身结束后的过渡等待设为 0，但当前引擎实际会限制为 3 秒；正常关闭热身时不应进入该过渡。已有部署更新配置后，需要重新启动服务端或加载地图才生效。

“停止检视服务”关闭独立服务端和数据库，网页继续运行，游戏客户端会断开本地连接但不会被强制关闭。想连网页后台一起关闭，运行 `Stop-Inspect.cmd`。

**回官匹前：完全退出此次 CS2，再从 Steam 正常打开。**

## 地图

控制台上方的地图选择框显示图标和中文名。每次打开或刷新页面默认选择“炙热沙城 II”，不会记忆上次选择，也不会因刷新页面自动改变正在运行的地图。

服务未启动时，选地图后点击“启动检视”；服务已启动时，选地图后点击“切换地图”。切图会重新加载地图，状态栏显示实际运行地图。饰品组合仍保存在本机；切图后可重新应用整组。

可选地图：炙热沙城 II、荒漠迷城、炼狱小镇、核子危机、死亡游乐园、远古遗迹、阿努比斯、列车停放站、殒命大厦、死城之谜。缺少地图文件时，该选项不可用。图标随程序部署，不需要额外下载。

## 饰品选择

在“枪械”“刀具”或“手套”中，先选类型，再选具体皮肤。例如，打开“手套”，选择“运动手套”，即可从下方列表挑选款式。

在“探员”中，先选 T（34 款）或 CT（29 款），再从带缩略图的列表选人。可以按名称或编号搜索当前阵营。点选后可看大图，直接应用或保存到组合。探员没有模板和磨损。

切换标签再回来时，网页会恢复之前的大类、款式、搜索词、编辑值和列表滚动位置。刷新页面会清空这些临时选择，已保存的组合仍可从“我的搭配”打开。

列表显示缩略图，右侧显示选中款式大图。图片首次按需下载，保存在安装目录 `data\preview-images`。已缓存图片可离线看，下载失败时点大图区域“重试图片”。它们是款式参考，不随模板、磨损或贴纸变化；对应实物效果要在游戏内检视。

### 模板与磨损

图案模板（0–1000）和磨损值（0–1）都可直接输入或拖动滑块。新选皮肤默认使用“略磨”的 0.11–0.15 档。要快速换磨损，先点第一排的等级，再点第二排的区间。每点一次区间，网页就在该范围内随机取值，保留四位小数。打开已保存的搭配会使用保存时的数值。

| 磨损等级 | 可选区间 |
| --- | --- |
| 崭新 | 0.00–0.01、0.01–0.02、0.02–0.03、0.03–0.04、0.04–0.07 |
| 略磨 | 0.07–0.08、0.08–0.09、0.09–0.10、0.10–0.11、0.11–0.15 |
| 久经 | 0.15–0.18、0.18–0.21、0.21–0.24、0.24–0.27、0.27–0.38 |
| 破损 | 0.38–0.39、0.39–0.40、0.40–0.41、0.41–0.42、0.42–0.45 |
| 战痕 | 0.45–0.50、0.50–0.63、0.63–0.76、0.76–0.90、0.90–1.00 |

枪械还可设置名称标签、StatTrak 和最多五张贴纸。贴纸采用默认位置与角度。

### 应用到游戏

点“应用到游戏”后会直接保存配装并通知本地插件，无需复制 moeub 的 sm_skin/sm_glove 指令。

| 应用内容 | 游戏行为 |
| --- | --- |
| 枪械 | 发放所选枪械，替换同槽位装备，切到对应枪械 |
| 刀具 | 替换刀具，切到持刀视角 |
| 手套 | 更新手套，保留当前持有视角 |
| 探员 | 将选中的模型同步给本地检视服的 T、CT 两队，保留当前武器 |

无法确认视角切换时会尝试恢复原持有视角，网页会显示确认结果。刚入图请先选阵营；角色死亡时先复活。按 F 检视，按 R 换弹。弹匣正常消耗、备用弹药无限。

仅切换页面选择不会应用到游戏。“刷新游戏饰品”只刷新当前装备，不再做两次整套刷新。

## 搭配组合

在“我的搭配”中点击“新建组合”。选好饰品及模板、磨损后，点击“保存搭配”，选择目标组合并保存；此操作不会改变游戏装备。

选择组合后点“应用整组”，可以一起应用主武器、手枪、刀具、手套和探员。组合中有多名探员时，两队都使用最后保存的那名。同一种武器、刀具或手套有多个方案时，也取最后保存的一款。不同枪械的皮肤都会保存，主武器和手枪槽位各发放最后保存的一把。

默认组合保留且不显示删除按钮。其他组合可通过垃圾桶图标删除，需再次确认；组合内单件饰品点击垃圾桶即可移除，无需确认。删除保存的方案不会改变游戏中已经应用的装备。

旧版 `data\presets.json` 在第一次启动新版网页后台时自动迁入默认组合，保留原有条目和重复方案。新数据写入 `data\outfit-groups.json`，旧文件保留作迁移前备份；已有组合文件时不会重复迁移。

## 文件与排查

- 本机配置和密钥：`data\settings.json`、`profile.json`、`secrets.json`。不要分享密钥文件。
- 个人组合：`data\outfit-groups.json`；旧搭配备份：`data\presets.json`。
- 图片：`data\preview-images`。
- 网页和数据库日志：`logs`。
- 游戏实际日志：`server\game\csgo\addons\metamod\console.log`。

更新网页或后台后，刷新页面一次加载新代码。旧验证令牌失效会自动获取并重试一次；持续失败时用 `127.0.0.1:17830` 重新打开。

若启动被防火墙检查阻止，重新运行 `Enable-Local-Isolation.cmd`；不要通过注释掉检查来启动。若普通 CS2 已在运行，退出后再启动检视。

## Steam 更新 CS2 后

等 Steam 下载完成，退出 CS2，在网页停止检视服务。双击安装目录的「更新检视服.cmd」，看到「更新完成」或「无需复制」后，照常启动检视。

脚本保留饰品插件、检视配置和个人组合。更新校验通过后自动删除本次临时备份。更新失败会自动回滚，回滚未完成时会保留备份并显示恢复路径。在安装目录运行 `.\更新检视服.cmd -CheckOnly` 可以只查看差异。
