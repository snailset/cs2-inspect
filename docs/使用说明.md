# CS2 本地检视控制台

## 启动与停止

打开安装目录的 `检视控制台.html`，点“打开本地检视控制台”，再点“启动检视”。备用入口是同目录 `打开检视控制台.cmd`。后台已启动时直接访问 <http://127.0.0.1:17830/>。

如果普通模式的 CS2 正在运行，先退出。启动器会通过 Steam 使用本次临时参数 `-insecure -console +connect 127.0.0.1:27015`，没有修改 Steam 永久启动选项。

等待地图加载后选阵营。若没有自动进入，在游戏控制台输入：

```text
connect 127.0.0.1:27015
```

服务端默认关闭联网/离线热身，将热身结束后的过渡等待设为 0。已有部署更新配置后，需要重新启动服务端或加载地图才生效。

“停止检视服务”关闭独立服务端和数据库，网页继续运行，游戏客户端会断开本地连接但不会被强制关闭。想连网页后台一起关闭，运行 `Stop-Inspect.cmd`。

**回官匹前：完全退出此次 CS2，再从 Steam 正常打开。**

## 饰品选择

先选“枪械 / 刀具 / 手套”，再选大类，最后选择具体皮肤。第二级搜索只搜索当前大类。已验证数据有 35 类枪械、20 类刀具、8 类手套，共 2161 个条目。

列表显示缩略图，右侧显示选中款式大图。图片首次按需下载，保存在安装目录 `data\preview-images`。已缓存图片可离线看，下载失败时点大图区域“重试图片”。它们是款式参考，不随模板、磨损或贴纸变化；对应实物效果要在游戏内检视。

图案模板范围 0–1000，磨损 0–1。枪械可设置名称标签、StatTrak 和最多五张贴纸；贴纸采用默认位置与角度，暂不提供自由移动/旋转。

点“应用到游戏”后会直接保存配装并通知本地插件，无需复制 moeub 的 sm_skin/sm_glove 指令。

| 应用内容 | 游戏行为 |
| --- | --- |
| 枪械 | 发放所选枪械，替换同槽位装备，切到对应枪械 |
| 刀具 | 替换刀具，切到持刀视角 |
| 手套 | 更新手套，保留当前持有视角 |

无法确认视角切换时会尝试恢复原持有视角，网页会显示确认结果。刚入图请先选阵营；角色死亡时先复活。按 F 检视，按 R 换弹。弹匣正常消耗、备用弹药无限。

仅切换页面选择不会应用到游戏。“刷新游戏饰品”只刷新当前装备，不再做两次整套刷新。

## 搭配组合

在“我的搭配”中点击“新建组合”。选好饰品及模板、磨损后，点击“保存搭配”，选择目标组合并保存；此操作不会改变游戏装备。

选择组合后点“应用整组”，可以一起应用主武器、手枪、刀具和手套，T/CT 两队同步。同一种武器、刀具或手套有多个方案时，使用最后保存的一款。不同枪械的皮肤都会保存，但主武器和手枪槽位各只发放最后保存的一把，步枪与手枪不会相互替换。

默认组合保留且不显示删除按钮。其他组合可通过垃圾桶图标删除，需再次确认；组合内单件饰品点击垃圾桶即可移除，无需确认。删除保存的方案不会改变游戏中已经应用的装备。

旧版 `data\presets.json` 在第一次启动新版网页后台时自动迁入默认组合，保留原有条目和重复方案。新数据写入 `data\outfit-groups.json`，旧文件保留作迁移前备份；已有组合文件时不会重复迁移。

## 文件与排查

- 本机配置和密钥：`data\settings.json`、`profile.json`、`secrets.json`。不要分享密钥文件。
- 个人组合：`data\outfit-groups.json`；旧搭配备份：`data\presets.json`。
- 图片：`data\preview-images`。
- 网页和数据库日志：`logs`。
- 游戏实际日志：`server\game\csgo\addons\metamod\console.log`。

更新网页或后台后，刷新页面一次加载新代码。旧验证令牌失效会自动获取并重试一次；持续失败时用 `127.0.0.1:17830` 重新打开。

若启动被防火墙检查阻止，重新运行 `Enable-Local-Isolation.cmd`；不要通过注释掉检查来启动。若普通 CS2 已在运行，退出后再启动检视。若游戏更新造成版本不一致，按仓库里的维护文档更新独立服务端和匹配插件。
